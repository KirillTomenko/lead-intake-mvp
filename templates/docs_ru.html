🔧 Системные методы

GET /health
Проверка работоспособности
Возвращает статус сервиса и версию.

📋 Методы работы с заявками

POST /lead
Создать новую заявку
Принимает данные клиента, сохраняет в базу и отправляет уведомление.
GET /leads
Получить все заявки
Возвращает список всех заявок из базы данных.
